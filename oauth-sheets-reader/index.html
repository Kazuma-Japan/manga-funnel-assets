Sheets Reader (personal tool)

This is a private, personal tool used only by the owner of this GitHub account (Kazuma-Japan). It reads Google Sheets that the owner already has access to, in read-only mode, to prepare the owner's own work reports.

It is not offered to the public and has no other users.
