Privacy Policy

Last updated: 2026-10-20

Sheets Reader is a personal tool used only by the owner of this GitHub account (Kazuma-Japan).

  • What it accesses: Google Sheets that the owner already has access to, using the read-only scope (spreadsheets.readonly). It cannot edit or delete anything.
  • How the data is used: only to prepare the owner's own work reports.
  • Sharing: the data is not sold and is not shared with third parties for advertising or any other purpose.
  • Storage: the access token is stored only on the owner's own computer. The owner can revoke access at any time from the Google Account permissions page.
  • Users: the tool has no users other than the owner.
  • Contact: please use the support email shown on the Google consent screen.
